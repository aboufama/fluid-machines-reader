# How Fluid Machines Work — study reader

[Open the reader](https://aboufama.github.io/fluid-machines-reader/#page=13)

A searchable, Wikipedia-inspired reader for Brian J. Kirby’s *How Fluid Machines Work*, 2022 edition. The book text is published with the author’s permission, as confirmed by the site maintainer. Text copyright © Brian J. Kirby; third-party images retain their credited rights. This repository does not grant a general redistribution license for the book or those images.

## Features

- Selectable text and rendered mathematics across 596 source pages.
- Chapter and section navigation with 143 completion checkboxes.
- Equation, problem and figure indexes with topic and equation-number filtering.
- Page and equation links that can be bookmarked or shared.
- Marginal definitions, haikus and editorial notes in a separate sidebar.
- Verified external photographs/source-video frames and 188 custom vector diagrams. No scanned pages or cropped book images are included.

Reading progress is saved in the current browser. It does not synchronize between devices.

## Review record

The reader’s [review record](https://aboufama.github.io/fluid-machines-reader/review.html) documents the checks and remaining source issues. The final mathematics pass applied 15 transcription fixes and 16 source clarifications. All 7,459 expressions render without syntax errors. Errors or damaged symbols in the source remain explicitly annotated.

Some original photographs could not be recovered. Their locations are marked unavailable. Frames recovered from source videos are labeled when their exact timing differs or remains uncertain.

## Hosting

This is a static site hosted by GitHub Pages from the `codex/reader-site` branch. It has no backend and works without the maintainer’s computer running. All runtime assets are bundled; KaTeX’s license is included under `vendor/katex/LICENSE`.
